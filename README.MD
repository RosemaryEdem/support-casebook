## How I Work

Each incident follows a consistent troubleshooting process:

1. **Ticket:** What the user reports
2. **Symptoms:** Errors and observable behaviour
3. **Diagnosis:** Investigation steps and evidence
4. **Root Cause:** The underlying reason for the issue
5. **Resolution:** The changes made to fix it
6. **Verification:** Tests confirming the outcome
7. **Prevention:** Steps to reduce the chance of recurrence
8. **Lessons Learned:** Key takeaways from the incident
